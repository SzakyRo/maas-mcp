# v0.5.0 — Networking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the networking surface (Fabric / Space / VLAN / Subnet / IP Range / Interface + bond/VLAN-assign writes + composite `network_layout` read) to the maasmcp curated layer — 35 new verbs, 14 new path helpers — bringing the curated surface to 78 verbs.

**Architecture:** New verbs follow the v0.3.0/v0.3.1/v0.4.0 pattern exactly: one file per verb class, `Annotated[MaasClient, SkipJsonSchema()]` first-param, `_validate_ids` for path validation, `confirm: bool = False` gate on every destructive verb, M2 schema-drift raise on `get_*` and `create_*` verbs that return a single object. Path helpers live in a new `_network_paths.py` sibling to `_storage_paths.py`. `network_layout` follows the same sequential-Stage-1 / data-driven-Stage-2 fetch discipline as `storage_summary`. All endpoints come verbatim from `maasapi.md`.

**Tech Stack:** Python 3.12+, FastMCP, Pydantic v2, respx (test mocking), pytest-asyncio, ruff, mypy --strict. Same stack as v0.4.0; no new dependencies.

## Global Constraints

These apply to every task. Re-read before each task's review.

- **No new dependencies.** Same `pyproject.toml` as v0.4.0.
- **`_validate_ids` is the only validator.** Every new verb validates its path IDs through `_validate_ids(system_id, ...)` — never inline `if not system_id` / `if id <= 0` blocks. The function lives in `_storage_paths.py` and is generic over ID names; networking verbs import it from there. No rename, no duplication. Cross-domain import is documented in `_network_paths.py`.
- **`confirm: bool = False` on every destructive verb.** Path validation runs BEFORE the confirm check, preserving the M6 invariant. Destructive networking verbs (22 total): Fabric (3): `create_fabric`, `update_fabric`, `delete_fabric`; Space (3): `create_space`, `update_space`, `delete_space`; VLAN (3): `create_vlan`, `update_vlan`, `delete_vlan`; Subnet (3): `create_subnet`, `update_subnet`, `delete_subnet`; IP Range (3): `create_ip_range`, `update_ip_range`, `delete_ip_range`; Interface (7): `create_interface`, `delete_interface`, `assign_vlan_to_interface`, `create_bond`, `create_bridge`, `create_interface_vlan`, `unlink_subnet`.
- **`Annotated[MaasClient, SkipJsonSchema()]` first-param pattern** on every verb's `run` signature.
- **MCPUpstreamError body-strip security fix (`5ad4a1a`) preserved.** Tests asserting on upstream errors continue to assert on the status code only (`"409" in str(exc_info.value)`), never on body text.
- **Schema-drift raise on non-dict upstream (M2).** Every `get_*` and `create_*` verb that returns a single object raises `ValueError(f"MAAS returned non-dict for <kind> <id> (got {type(resp).__name__}); schema drift?")`. M2-raise verbs in v0.5.0 (18 total): `get_fabric`, `create_fabric`, `get_space`, `create_space`, `get_vlan`, `create_vlan`, `get_subnet`, `create_subnet`, `get_ip_range`, `create_ip_range`, `get_interface`, `create_interface`, `assign_vlan_to_interface`, `create_bond`, `create_bridge`, `create_interface_vlan`, `unlink_subnet` (returns dict from MAAS).
- **`MaasClient.post()` signature is `async def post(self, path, *, json=None) -> Any`.** All POST/PUT verbs call `client.post(path, json=body)` or `client.put(path, json=body)` with a plain dict.
- **`MaasClient.delete()` exists** for `delete_*` verbs. Signature: `async def delete(self, path: str) -> Any`. Verify in `src/maasmcp/maas/client.py` before Task 2; if absent, fall back to `client.post(path, json={})` per v0.3.0 `delete_block_device` precedent.
- **MAAS authority.** Every endpoint shape, body field name, and response contract comes from `maasapi.md` at the project root.
- **Flat layout under `src/maasmcp/curated/`.** No subpackage. Networking verbs sit alongside the existing 43. Path helpers live in new `_network_paths.py`.
- **Test fixture pattern (v0.1.1):** Tests that build a `MaasClient` directly via `MaasmcpConfig.load(None)` must first seed env vars because `tests/conftest.py` autouses `_isolate_settings_env` and `MaasmcpConfig` requires `maas`+`server` sub-configs:
  ```python
  monkeypatch.setenv("MAASMCP_MAAS__BASE_URL", "https://maas.example.com/MAAS")
  monkeypatch.setenv("MAASMCP_MAAS__API_KEY", "k")
  monkeypatch.setenv("MAASMCP_SERVER__BEARER_TOKEN", "t")
  ```
  Then `client = MaasClient(cfg.maas)` and assign `client.base_url = cfg.maas.base_url` so `respx.mock(base_url=maas_client.base_url)` targets the right host. Wrap each test body in `async with maas_client:` inside `respx.mock(...)`.
- **Naming for nested interface ops.** Cluster-level `create_vlan` (under `/vlans/`) is distinct from nested `create_interface_vlan` (under `/nodes/{sid}/interfaces/{id}/op-create_vlan`). Per-verb tasks include a "name confusion test" asserting `create_vlan.path != create_interface_vlan.path`.
- **`network_layout` Stage 2 depends on Stage 1.** If `list_interfaces` fails, the verb returns `partial=True` plus an `errors` list and a partial tree.
- **Local-only, no PyPI publish, no push.** Matches v0.3.0 / v0.3.1 / v0.4.0 precedent.
- **`v0.5.0` tag at post-review HEAD.** No push.

#### Pre-step: add `_validate_id` helper

`_validate_ids` requires a non-empty `system_id` unconditionally. Networking verbs at the cluster scope (Fabric, Space, VLAN, Subnet, IP Range) don't carry a `system_id`. Extend `_storage_paths.py` with a single-id sibling:

```python
def _validate_id(**ids: int) -> None:
    """Validate a single MAAS path ID for non-machine-scoped verbs.

    For Fabric/Space/VLAN/Subnet/IP Range endpoints which don't take a
    system_id, use this in place of ``_validate_ids``. Same error format.
    """
    for name, value in ids.items():
        if value <= 0:
            raise ValueError(f"{name} must be > 0, got {value}")
```

def _validate_id(**ids: int) -> None:
    """Validate a single MAAS path ID for non-machine-scoped verbs.

    For Fabric/Space/VLAN/Subnet/IP Range endpoints which don't take a
    system_id, use this in place of ``_validate_ids``. Same error format.
    """
    for name, value in ids.items():
        if value <= 0:
            raise ValueError(f"{name} must be > 0, got {value}")

                f"MAAS returned non-dict for created fabric "
                f"(got {type(resp).__name__}); schema drift?"

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._network_paths import _validate_id, vlans_path
from maasmcp.maas.client import MaasClient


class CreateVlanTool:
    name = "create_vlan"
    description = (
        "Create a VLAN on a fabric. DESTRUCTIVE (cluster-wide) — pass confirm=True. "
        "Returns the newly-created VLAN dict. Use create_interface_vlan for "
        "the nested interface-scoped variant."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        vid: int,
        fabric_id: int,
        name: str | None = None,
        description: str | None = None,
        confirm: bool = False,
    ) -> dict[str, Any]:
        if not 1 <= vid <= 4094:
            raise ValueError(
                f"vlan vid must be in 1..4094 (got {vid})"
            )
        _validate_id(fabric_id=fabric_id)
        if confirm is not True:
            raise ValueError(
                "create_vlan is destructive; pass confirm=True to proceed. "
                f"Affected: vid={vid}, fabric_id={fabric_id}"
            )
        body: dict[str, Any] = {"vid": vid, "fabric": fabric_id}
        if name is not None:
            body["name"] = name
        if description is not None:
            body["description"] = description
        resp = await client.post(vlans_path(), json=body)
        if not isinstance(resp, dict):
            raise ValueError(
                f"MAAS returned non-dict for created vlan "
                f"(got {type(resp).__name__}); schema drift?"
            )
        return resp

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)

            "start_ip": start_ip,
            "end_ip": end_ip,
            "type": type,

"""list_interfaces: GET /nodes/{system_id}/interfaces/."""

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._network_paths import _validate_ids, interfaces_path
from maasmcp.maas.client import MaasClient


class ListInterfacesTool:
    name = "list_interfaces"
    description = "List all interfaces on a MAAS machine. Returns MAAS's response (list of dicts). Use get_interface to drill into one."

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
    ) -> list[dict[str, Any]]:
        _validate_ids(system_id)
        resp = await client.get(interfaces_path(system_id))
        if isinstance(resp, dict) and "interfaces" in resp:
            return list(resp["interfaces"])
        if isinstance(resp, list):
            return resp
        return []

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

"""get_interface: GET /nodes/{system_id}/interfaces/{id}/."""

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._network_paths import _validate_ids, interface_path
from maasmcp.maas.client import MaasClient


class GetInterfaceTool:
    name = "get_interface"
    description = "Fetch one interface by system_id + iface_id. Returns the MAAS interface dict. Use list_interfaces to find IDs first."

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
        iface_id: int,
    ) -> dict[str, Any]:
        _validate_ids(system_id, iface_id=iface_id)
        resp = await client.get(interface_path(system_id, iface_id))
        if not isinstance(resp, dict):
            raise ValueError(
                f"MAAS returned non-dict for interface {iface_id} "
                f"(got {type(resp).__name__}); schema drift?"
            )
        return resp

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

def test_name_confusion_paths_differ():
    """Cluster-level create_vlan uses /vlans/; nested create_interface_vlan
    uses /nodes/{sid}/interfaces/{id}/op-create_vlan. The verb names are
    intentionally distinct to disambiguate."""
    from maasmcp.curated._network_paths import (
        vlans_path, vlan_path, interface_op_path,
    )
    assert vlans_path() == "/api/2.0/vlans/"
    assert vlan_path(5) == "/api/2.0/vlans/5/"
    assert interface_op_path("abc", 8, "op-create_vlan") == \
        "/api/2.0/nodes/abc/interfaces/8/op-create_vlan"
    # Confirm no overlap
    assert not vlans_path().startswith("/nodes/")
    assert not interface_op_path("abc", 8, "op-create_vlan").startswith("/vlans/")

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._network_paths import _validate_ids, interfaces_path
from maasmcp.maas.client import MaasClient


class CreateInterfaceTool:
    name = "create_interface"
    description = (
        "Create a virtual interface on a MAAS machine. DESTRUCTIVE — pass confirm=True. "
        "Returns the newly-created interface dict. For physical NICs, use MAAS's "
        "auto-discovery (enlist + commission); this verb is for vLANs/bonds/bridges."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
        name: str,
        mac_address: str | None = None,
        vlan: int | None = None,
        tags: list[str] | None = None,
        confirm: bool = False,
    ) -> dict[str, Any]:
        _validate_ids(system_id)
        if vlan is not None:
            _validate_id(vlan=vlan)
        if confirm is not True:
            raise ValueError(
                "create_interface is destructive; pass confirm=True to proceed. "
                f"Affected: system_id={system_id}, name={name}"
            )
        body: dict[str, Any] = {"name": name}
        if mac_address is not None:
            body["mac_address"] = mac_address
        if vlan is not None:
            body["vlan"] = vlan
        if tags is not None:
            body["tags"] = tags
        resp = await client.post(interfaces_path(system_id), json=body)
        if not isinstance(resp, dict):
            raise ValueError(
                f"MAAS returned non-dict for created interface "
                f"(got {type(resp).__name__}); schema drift?"
            )
        return resp

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)

```python
"""network_layout: composite read of a machine's network topology.

Sequential Stage 1 (small cluster-wide lists + the machine's interface list)
followed by data-driven Stage 2 (per-fabric VLAN fan-out once Stage 1 reveals
which fabrics the machine touches). Final assembly is in-memory join.

If any Stage 1 gather raises, the verb returns partial=True plus an errors
list and a partial tree; the agent can decide whether the partial info is
sufficient or whether to retry.
"""

from __future__ import annotations

import asyncio
from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._network_paths import (
    _validate_ids,
    fabric_vlans_path,
    fabrics_path,
    interfaces_path,
    spaces_path,
    subnets_path,
    vlan_path,
)
from maasmcp.maas.client import MaasClient


def _parse_list(resp: Any, key: str) -> list[dict[str, Any]]:
    """Accept wrapped {key: [...]} or bare-list shapes."""
    if isinstance(resp, dict) and key in resp:
        return list(resp[key])
    if isinstance(resp, list):
        return resp
    return []


class NetworkLayoutTool:
    name = "network_layout"
    description = (
        "Composite read of a machine's full network topology in one call. "
        "Returns interface→VLAN→subnet→fabric tree per v0.5.0 spec Section 8. "
        "Sequential Stage 1 (interfaces + small cluster-wide lists); data-driven "
        "Stage 2 (per-fabric VLAN fan-out). Returns partial=True plus errors if "
        "Stage 1 fails — the agent can decide whether to retry."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
    ) -> dict[str, Any]:
        _validate_ids(system_id)

        # Stage 1 — parallel fat gather
        results = await asyncio.gather(
            client.get(interfaces_path(system_id)),
            client.get(fabrics_path()),
            client.get(spaces_path()),
            client.get(subnets_path()),
            return_exceptions=True,
        )
        ifaces_resp, fabrics_resp, spaces_resp, subnets_resp = results
        errors: list[str] = []

        interfaces: list[dict[str, Any]] = []
        if isinstance(ifaces_resp, BaseException):
            errors.append(f"list_interfaces: {ifaces_resp!r}")
        else:
            interfaces = _parse_list(ifaces_resp, "interfaces")
        fabrics: list[dict[str, Any]] = []
        if isinstance(fabrics_resp, BaseException):
            errors.append(f"list_fabrics: {fabrics_resp!r}")
        else:
            fabrics = _parse_list(fabrics_resp, "fabrics")
        spaces: list[dict[str, Any]] = []
        if isinstance(spaces_resp, BaseException):
            errors.append(f"list_spaces: {spaces_resp!r}")
        else:
            spaces = _parse_list(spaces_resp, "spaces")
        subnets: list[dict[str, Any]] = []
        if isinstance(subnets_resp, BaseException):
            errors.append(f"list_subnets: {subnets_resp!r}")
        else:
            subnets = _parse_list(subnets_resp, "subnets")

        # Stage 2 — data-driven per-fabric VLAN fan-out
        # We don't need every VLAN on every fabric — only the VLANs the
        # machine's interfaces touch. Dedup by vlan_id.
        touched_vlan_ids: set[int] = set()
        for iface in interfaces:
            v = iface.get("vlan_id")
            if isinstance(v, int):
                touched_vlan_ids.add(v)
            # also catch nested vlan fields the agent may inspect
            v2 = iface.get("vlan")
            if isinstance(v2, dict) and isinstance(v2.get("id"), int):
                touched_vlan_ids.add(v2["id"])

        vlan_lookups = await asyncio.gather(
            *(client.get(vlan_path(vid)) for vid in sorted(touched_vlan_ids)),
            return_exceptions=True,
        )
        vlan_by_id: dict[int, dict[str, Any]] = {}
        for vid, resp in zip(sorted(touched_vlan_ids), vlan_lookups):
            if isinstance(resp, BaseException):
                errors.append(f"get_vlan({vid}): {resp!r}")
            elif isinstance(resp, dict):
                vlan_by_id[vid] = resp

        # Also fetch per-fabric VLAN lists to compute fabric-level counts.
        fabric_vlan_results = await asyncio.gather(
            *(client.get(fabric_vlans_path(f["id"])) for f in fabrics if isinstance(f.get("id"), int)),
            return_exceptions=True,
        )
        fabric_vlan_counts: dict[int, int] = {}
        for fabric, resp in zip(fabrics, fabric_vlan_results):
            fid = fabric.get("id")
            if not isinstance(fid, int):
                continue
            if isinstance(resp, BaseException):
                errors.append(f"list_fabric_vlans({fid}): {resp!r}")
                fabric_vlan_counts[fid] = 0
            else:
                fabric_vlan_counts[fid] = len(_parse_list(resp, "vlans"))

        # Stage 3 — in-memory join
        subnet_by_id = {s["id"]: s for s in subnets if isinstance(s, dict) and "id" in s}

        # Subnets the machine touches: any subnet whose vlan matches an interface vlan
        touched_subnet_ids: set[int] = set()
        for iface in interfaces:
            vid = iface.get("vlan_id")
            if isinstance(vid, int):
                for sid, s in subnet_by_id.items():
                    if s.get("vlan") == vid:
                        touched_subnet_ids.add(sid)

        # IP ranges: count for v0.5.0 is 0 (no per-subnet IP-range fetch wired
        # yet); spec notes that explicit per-subnet list_ip_ranges may be
        # required for full info.
        ip_range_count = 0

        joined_interfaces: list[dict[str, Any]] = []
        for iface in interfaces:
            v = iface.get("vlan_id")
            vlan_obj: dict[str, Any] | None = None
            if isinstance(v, int) and v in vlan_by_id:
                vl = vlan_by_id[v]
                vlan_obj = {
                    "id": vl.get("id", v),
                    "name": vl.get("name"),
                    "vid": vl.get("vid"),
                    "fabric_id": vl.get("fabric"),
                }
            linked_subnet: dict[str, Any] | None = None
            if isinstance(v, int):
                for sid in touched_subnet_ids:
                    s = subnet_by_id.get(sid, {})
                    if s.get("vlan") == v:
                        linked_subnet = {
                            "id": s.get("id"),
                            "cidr": s.get("cidr"),
                            "gateway_ip": s.get("gateway_ip"),
                        }
                        break
            parents = iface.get("parents") or []
            joined_interfaces.append({
                "id": iface.get("id"),
                "name": iface.get("name"),
                "type": iface.get("type", "unknown"),
                "mac_address": iface.get("mac_address"),
                "vlan": vlan_obj,
                "linked_subnet": linked_subnet,
                "parents": list(parents) if isinstance(parents, list) else [],
                "children": [],  # populated below
                "ip_addresses": list(iface.get("ip_addresses") or []),
            })

        # Populate children for parent interfaces
        for child in joined_interfaces:
            for parent_id in child["parents"]:
                for parent in joined_interfaces:
                    if parent["id"] == parent_id:
                        parent["children"].append(child["id"])

        return {
            "system_id": system_id,
            "fabric_count": len(fabrics),
            "vlan_count": len(vlan_by_id),
            "subnet_count": len(touched_subnet_ids),
            "interface_count": len(joined_interfaces),
            "ip_range_count": ip_range_count,
            "interfaces": joined_interfaces,
            "partial": bool(errors),
            "errors": errors,
            "fabric_vlan_counts": fabric_vlan_counts,
        }

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```
