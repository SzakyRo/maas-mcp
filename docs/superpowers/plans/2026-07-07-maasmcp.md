# maasmcp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `maasmcp` — an MCP server exposing Canonical MAAS bare-metal provisioning to LLM agents, via streamable-HTTP transport, with a code-generated tool layer for the full MAAS API surface plus 12 hand-written curated verbs, packaged as `pip install maasmcp`.

**Architecture:** Python ≥3.11 package. Build-time tool generator consumes MAAS's `/api/2.0/describe/` JSON and emits one Pydantic-typed MCP tool per MAAS operation (committed to `src/maasmcp/_generated/`). Hand-written curated verbs compose generated tools into opinionated workflows. Runtime is a Starlette + uvicorn + FastMCP server, auth via static bearer token, upstream MAAS auth via API key or OAuth1. Six-layer test strategy; generated code is exempt from coverage.

**Tech Stack:** Python ≥3.11, FastMCP (`mcp[cli]`), httpx, pydantic ≥2.5, pydantic-settings, structlog, starlette, uvicorn[standard], typer, PyYAML; dev: pytest, pytest-asyncio, pytest-cov, respx, ruff, mypy, hatchling.

**Spec:** `docs/superpowers/specs/2026-07-07-maasmcp-design.md`

## Global Constraints

- **Python:** `>=3.11` (uses `tomllib`, modern type hints, `StrEnum`).
- **Runtime deps (exact):** `httpx`, `mcp[cli]`, `pydantic>=2.5`, `pydantic-settings`, `structlog`, `starlette`, `uvicorn[standard]`, `typer`, `PyYAML`.
- **Dev deps (exact):** `pytest`, `pytest-asyncio`, `pytest-cov`, `respx`, `ruff`, `mypy`, `hatchling`.
- **MAAS upstream retry policy:** 5xx retries up to 3 times with exponential backoff at **250ms / 1s / 4s**; on final failure surface `MCPUpstreamError` with last status + URL.
- **Network timeout:** same retry policy; on final failure surface `MCPUpstreamTimeout`.
- **MAAS 4xx behavior:** pass through MAAS error JSON verbatim in `isError=true` MCP tool result.
- **Auth — client→server:** static bearer token in `Authorization: Bearer <token>`, compared with `hmac.compare_digest`. Env var `MAASMCP_BEARER_TOKEN` or `server.bearer_token` in YAML. Binary valid/invalid; no scopes.
- **Auth — server→MAAS:** `api_key` (default) via `MAAS_API_KEY` env var, or `oauth` (consumer_key/secret/token/token_secret). Validate on startup; refuse to start if missing.
- **Server bind:** `0.0.0.0:$MAASMCP_PORT`, default port `8765`. Single asyncio loop.
- **`/healthz`:** mounted alongside MCP routes, **exempt from auth**.
- **Pagination default cap:** `max_paginated_items: 1000`. `paginate: bool = False` returns one page and ignores the cap.
- **Logging:** `structlog` JSON to stdout. Per MCP request: client IP, bearer-token prefix (first 6 chars, never full token), tool name, latency, outcome. Per MAAS upstream call: method, path with path params replaced by `{name}`, status, latency. **No request bodies, no full tokens in logs.**
- **Coverage thresholds:** curated ≥85%, MAAS client ≥80%, generator ≥80%. **Generated layer is exempt** from coverage.
- **Commit messages:** Conventional Commits (`feat:`, `fix:`, `chore:`, `test:`, `docs:`, `refactor:`).
- **PR convention for MAAS API regen:** title `chore(regen): MAAS 3.X.Y → 3.Y.Z`, description links to MAAS release notes.
- **License:** Apache-2.0.
- **Package version:** start at `0.1.0`.
- **Layout:** `src/maasmcp/` package layout, `tests/` mirroring source layout.

```python
_PLACEHOLDER_RE = re.compile(r"\$\{([A-Z_][A-Z0-9_]*)\}")


def _expand_env(text: str) -> str:
    """Expand ${VAR} placeholders, raising RuntimeError on missing vars."""
    def repl(match: re.Match[str]) -> str:
        var = match.group(1)
        try:
            return os.environ[var]

            raise RuntimeError(f"Environment variable {var} is referenced in config but not set") from exc

        if self.yaml_path is None:

def yaml_path_load_with_expansion(path: Path) -> dict[str, Any]:
    """Load YAML with ${VAR} expansion on every string leaf."""
    text = path.read_text()
    expanded = _expand_env(text)
    data = yaml.safe_load(expanded)
    if data is None:
        return {}
    return _expand_recursive(data)

    if isinstance(node, str):
        return _expand_env(node)
    if isinstance(node, dict):
        return {k: _expand_recursive(v) for k, v in node.items()}
    if isinstance(node, list):
        return [_expand_recursive(v) for v in node]
    return node
```

```python
"""Auto-pagination helpers for MAAS list endpoints."""

from __future__ import annotations

from typing import AsyncIterator, TypeVar

from maasmcp.maas.errors import PaginationCapExceeded

T = TypeVar("T")


async def paginate(source: AsyncIterator[T], *, max_items: int) -> AsyncIterator[T]:
    """Yield items from `source` up to `max_items`. Raises PaginationCapExceeded
    if the cap is hit and the source could yield more."""
    yielded = 0
    more_available = False
    async for item in source:
        if yielded >= max_items:
            more_available = True
            break
        yielded += 1
        yield item
    if more_available:
        raise PaginationCapExceeded(
            f"pagination hit cap of {max_items} items",
            cap=max_items,
        )
```

```python
"""Async HTTP client for the MAAS REST API."""

from __future__ import annotations

import asyncio
import hashlib
import hmac
import secrets
import time
import urllib.parse
from typing import Any

import httpx
import structlog

from maasmcp.config import MaasConfig
from maasmcp.maas.errors import MAASAuthError, MCPUpstreamError, MCPUpstreamTimeout

log = structlog.get_logger(__name__)

_RETRY_DELAYS_S = (0.25, 1.0, 4.0)
_MAX_ATTEMPTS = 4  # 1 initial + 3 retries


class MaasClient:
    """Async context-managed MAAS HTTP client.

    Auth modes (selected by which MaasConfig fields are populated):
    - api_key:  Authorization: Bearer <api_key>
    - oauth:    OAuth1 signed Authorization header
    """

    def __init__(self, cfg: MaasConfig, *, timeout_seconds: int = 60) -> None:
        self._cfg = cfg
        self._timeout = timeout_seconds
        self._client: httpx.AsyncClient | None = None
        self._auth_mode = self._resolve_auth_mode(cfg)

    @staticmethod
    def _resolve_auth_mode(cfg: MaasConfig) -> str:
        has_oauth = all([cfg.consumer_key, cfg.consumer_secret, cfg.token_key, cfg.token_secret])
        has_api = bool(cfg.api_key)
        if has_oauth and has_api:
            raise MAASAuthError("MaasConfig has both api_key and oauth credentials; pick one")
        if has_oauth:
            return "oauth"
        if has_api:
            return "api_key"
        raise MAASAuthError("MaasConfig has neither api_key nor full oauth credentials")

    async def __aenter__(self) -> "MaasClient":
        self._client = httpx.AsyncClient(
            base_url=self._cfg.base_url,
            timeout=self._timeout,
            verify=self._cfg.verify_tls,
        )
        return self

    async def __aexit__(self, exc_type: Any, exc: Any, tb: Any) -> None:
        if self._client is not None:
            await self._client.aclose()
            self._client = None

    # -- public verbs -------------------------------------------------------

    async def get(self, path: str, params: dict[str, Any] | None = None) -> Any:
        return await self._request("GET", path, params=params)

    async def post(self, path: str, json: dict[str, Any] | None = None) -> Any:
        return await self._request("POST", path, json_body=json)

    async def put(self, path: str, json: dict[str, Any] | None = None) -> Any:
        return await self._request("PUT", path, json_body=json)

    async def delete(self, path: str) -> Any:
        return await self._request("DELETE", path)

    # -- internals ----------------------------------------------------------

    async def _request(
        self,
        method: str,
        path: str,
        *,
        params: dict[str, Any] | None = None,
        json_body: dict[str, Any] | None = None,
    ) -> Any:
        assert self._client is not None, "MaasClient used outside `async with`"

        last_exc: Exception | None = None
        for attempt in range(_MAX_ATTEMPTS):
            try:
                headers = self._auth_headers(method, path, params=params, body=json_body)
                response = await self._client.request(
                    method, path, params=params, json=json_body, headers=headers
                )
            except httpx.TimeoutException as exc:
                last_exc = exc
                self._log_upstream(method, path, "<timeout>", attempt, retrying=True)
                await self._sleep_backoff(attempt)
                continue

            self._log_upstream(method, path, response.status_code, attempt, retrying=False)

            if response.status_code >= 500:
                last_exc = MCPUpstreamError(
                    f"upstream {response.status_code}",
                    status_code=response.status_code,
                    url=str(response.request.url),
                )
                await self._sleep_backoff(attempt)
                continue

            if response.status_code >= 400:
                raise MCPUpstreamError(
                    f"upstream {response.status_code}: {response.text[:200]}",
                    status_code=response.status_code,
                    url=str(response.request.url),
                )

            return self._parse_response(response)

        # Exhausted retries
        if isinstance(last_exc, MCPUpstreamError):
            raise last_exc
        raise MCPUpstreamTimeout(
            "upstream timed out after retries", url=self._full_url(path, params)
        )

    @staticmethod
    async def _sleep_backoff(attempt: int) -> None:
        """attempt is 0-indexed; we sleep before the NEXT attempt."""
        if attempt >= len(_RETRY_DELAYS_S):
            return
        await asyncio.sleep(_RETRY_DELAYS_S[attempt])

    def _full_url(self, path: str, params: dict[str, Any] | None) -> str:
        url = self._cfg.base_url.rstrip("/") + path
        if params:
            url = url + "?" + urllib.parse.urlencode(params)
        return url

    def _auth_headers(
        self,
        method: str,
        path: str,
        *,
        params: dict[str, Any] | None,
        body: dict[str, Any] | None,
    ) -> dict[str, str]:
        if self._auth_mode == "api_key":
            assert self._cfg.api_key
            return {"Authorization": f"Bearer {self._cfg.api_key}"}
        return self._oauth_header(method, path, params=params, body=body)

    def _oauth_header(
        self,
        method: str,
        path: str,
        *,
        params: dict[str, Any] | None,
        body: dict[str, Any] | None,
    ) -> dict[str, str]:
        assert all([self._cfg.consumer_key, self._cfg.consumer_secret,
                    self._cfg.token_key, self._cfg.token_secret])
        oauth_params = {
            "oauth_consumer_key": self._cfg.consumer_key or "",
            "oauth_token": self._cfg.token_key or "",
            "oauth_nonce": secrets.token_hex(16),
            "oauth_timestamp": str(int(time.time())),
            "oauth_signature_method": "PLAINTEXT",
            "oauth_version": "1.0",
        }
        # Per MAAS docs, the signature is PLAINTEXT: consumer_secret&token_secret
        oauth_params["oauth_signature"] = (
```

```python
"""Bearer-token ASGI auth middleware."""

from __future__ import annotations

import hmac

from starlette.middleware import Middleware
from starlette.requests import Request
from starlette.responses import Response
from starlette.types import ASGIApp, Receive, Scope, Send

EXEMPT_PATHS = frozenset({"/healthz"})


def require_bearer(expected_token: str) -> Middleware:
    """Return a Starlette middleware that requires a matching bearer token.

    Exempt paths: /healthz. Comparison uses hmac.compare_digest. Failures
    return a bare 401 with no body (so we don't leak why auth failed).
    """
    return Middleware(_BearerAuth, expected_token=expected_token)


class _BearerAuth:
    def __init__(self, app: ASGIApp, *, expected_token: str) -> None:
        self.app = app
        self.expected_token = expected_token

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] != "http":
            await self.app(scope, receive, send)
            return

        path = scope.get("path", "")
        if path in EXEMPT_PATHS:
            await self.app(scope, receive, send)
            return

        headers = dict(scope.get("headers", []))
        auth = headers.get(b"authorization", b"").decode("ascii", errors="replace")
        presented = ""
        if auth.startswith("Bearer "):
            presented = auth[len("Bearer "):]

        if hmac.compare_digest(presented, self.expected_token):
            await self.app(scope, receive, send)
            return

        response = Response(status_code=401)
        await response(scope, receive, send)
```

```python
"""Generate Pydantic-typed MCP tools from a MAAS /describe/ snapshot."""

from __future__ import annotations

import keyword
import re
from typing import Any

# Reserved Python keywords we can never use as parameter names without _ suffix.
_KEYWORDS = set(keyword.kwlist) | {"self", "cls"}


def _safe_param(name: str) -> str:
    return name + "_" if name in _KEYWORDS else name


def _to_python_type(schema: dict[str, Any]) -> str:
    """Translate a MAAS parameter schema leaf to a Python type annotation."""
    t = schema.get("type")
    if t == "string":
        return "str"
    if t == "integer":
        return "int"
    if t == "number":
        return "float"
    if t == "boolean":
        return "bool"
    if t == "array":
        item = _to_python_type(schema.get("items", {"type": "string"}))
        return f"list[{item}]"
    if t == "object":
        return "dict"
    return "Any"


def _split_path_params(parameters: dict[str, Any]) -> tuple[list[str], dict[str, Any]]:
    """Path params come from {name} placeholders in the operation path;
    they are required and excluded from the Pydantic body model."""
    # We don't have the path string here at the param layer; the path string
    # is processed at the per-operation level. Caller provides it.
    raise NotImplementedError("use _operation_inputs directly")


def _operation_inputs(
    op_path: str, parameters: dict[str, Any]
) -> tuple[list[str], list[tuple[str, str, str, bool]]]:
    """Return (path_param_names, [(py_name, type_str, description, required), ...])."""
    path_names = re.findall(r"\{([a-zA-Z_][a-zA-Z0-9_]*)\}", op_path)
    props = parameters.get("properties", {}) or {}
    required = set(parameters.get("required", []) or [])
    fields: list[tuple[str, str, str, bool]] = []
    for name, schema in props.items():
        if name in path_names:
            continue
        py_name = _safe_param(name)
        fields.append(
            (py_name, _to_python_type(schema), schema.get("description", ""), name in required)
        )
    return path_names, fields


def _render_input_model(
    class_name: str, fields: list[tuple[str, str, str, bool]]
) -> str:
    lines = [f"class {class_name}(BaseModel):", '    """Generated input model."""']
    if not fields:
        lines.append("    pass")
    for py_name, type_str, desc, required in fields:
        if required:
            lines.append(f"    {py_name}: {type_str} = Field(..., description={desc!r})")
        else:
            lines.append(f"    {py_name}: {type_str} | None = Field(default=None, description={desc!r})")
    return "\n".join(lines) + "\n"


def _render_tool_module(
    resource: str,
    operation: str,
    op: dict[str, Any],
) -> str:
    method = op["method"].upper()
    path = op["path"]
    op_name = f"{resource}_{operation}"
    input_class = "".join(part.capitalize() for part in op_name.split("_")) + "Input"

    path_names, fields = _operation_inputs(path, op.get("parameters", {}))
    path_args = ", ".join(path_names) if path_names else ""

    # Build the path string template: replace {name} with f"{{{name}}}"
    py_path = path
    for n in path_names:
        py_path = py_path.replace("{" + n + "}", "{" + n + "}")
    py_path = '"' + py_path.replace('"', '\\"') + '"'

    # Build kwargs for non-path fields
    if fields:
        kwarg_lines = [
            f"        {py_name}=payload.{py_name},"
            for (py_name, _t, _d, _r) in fields
        ]
        kwargs_block = "\n".join(kwarg_lines)
    else:
        kwargs_block = ""

    body_or_params = ""
    if method in {"POST", "PUT"}:
        body_or_params = "json_body=payload.model_dump(exclude_none=True)"
    elif fields:
        body_or_params = (
            "params=payload.model_dump(exclude_none=True, mode='json')"
        )

    description = (
        f"MAAS operation {method} /{path} on resource '{resource}'."
    )

    # Compose the final module
    input_model_src = _render_input_model(input_class, fields)
    return f'''"""Auto-generated MAAS tool: {method} /{path}."""

from __future__ import annotations

from pydantic import BaseModel, Field

from maasmcp.maas.client import MaasClient
from maasmcp.maas.errors import MCPUpstreamError


{input_model_src}


@mcp.tool(name="{op_name}", description={description!r})
async def {op_name}(
    client: MaasClient,
{("    " + path_args + ",") if path_args else ""}    payload: {input_class},
) -> list[dict] | dict | None:
    """{description}"""
    path = f{py_path}
    {body_or_params and (f"return await client.{method.lower()}(" + "path, " + body_or_params + ")") or f"return await client.{method.lower()}(path)"}

'''


def generate_tools(snapshot: dict[str, Any]) -> dict[str, str]:
    """Return {relative_path: source_code} for the generated tool modules."""
    out: dict[str, str] = {}
    for resource_obj in snapshot.get("resources", []):
        resource = resource_obj["name"]
        for operation, op in resource_obj.get("operations", {}).items():
            out[f"tools/{resource}_{operation}.py"] = _render_tool_module(resource, operation, op)
    return out

    imports = sorted(

        for resource_obj in snapshot.get("resources", [])
        for operation in resource_obj.get("operations", {}).keys()
        for resource_obj2 in [resource_obj]
        for resource in [resource_obj2["name"]]
    )
    body = "\n".join(imports)
    return f'''"""Auto-generated registry of every MAAS-derived MCP tool."""

mcp = FastMCP(name="maasmcp-generated")

{body}
'''
```

```python
"""acquire_machine: find an idle machine matching constraints and allocate it."""

from __future__ import annotations

from mcp.server.fastmcp import FastMCP

from maasmcp.maas.client import MaasClient


class AcquireMachineTool:
    """Find an idle machine and allocate it. Non-idempotent."""

    name = "acquire_machine"
    description = (
        "Find an idle machine matching the given constraints (hostname pattern, "
        "pool, status), allocate it via MAAS, and return the system_id plus "
        "current power state. Non-idempotent: MAAS allocates the first matching "
        "machine each call."
    )

    async def run(
        self,
        client: MaasClient,
        hostname: str | None = None,
        pool: str | None = None,
        status: str = "READY",
    ) -> dict:
        params: dict = {"status": status}
        if hostname:
            params["hostname"] = hostname
        machines = await client.get("/api/2.0/machines/", params=params)
        if not machines:
            raise ValueError(f"no machine matches constraints: {params}")
        chosen = machines[0]
        body: dict = {"system_id": chosen["system_id"]}
        if pool:
            body["pool"] = pool
        if hostname:
            body["hostname"] = hostname
        await client.post("/api/2.0/machines/allocate/", json_body=body)
        return {
            "system_id": chosen["system_id"],
            "hostname": chosen.get("hostname"),
            "status": chosen.get("status"),
        }

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

```python
from __future__ import annotations

from mcp.server.fastmcp import FastMCP

from maasmcp.maas.client import MaasClient

_ALLOWED = {"on", "off", "cycle"}


class PowerControlTool:
    name = "power_control"
    description = (
        "Power a machine on, off, or cycle it. Action must be one of on/off/cycle. "
        "Refuses to power off a machine currently in DEPLOYING or COMMISSIONING status."
    )

    async def run(
        self, client: MaasClient, system_id: str, action: str
    ) -> dict | None:
        if action not in _ALLOWED:
            raise ValueError(f"action must be one of {sorted(_ALLOWED)}, got {action!r}")
        if action == "off":
            machine = await client.get(f"/api/2.0/machines/{system_id}/")
            if isinstance(machine, dict):
                status = machine.get("status_name", "")
                if status in {"DEPLOYING", "COMMISSIONING"}:
                    raise ValueError(
                        f"refusing to power off machine in {status!r} status"
                    )
        path = f"/api/2.0/machines/{system_id}/power/"  # canonical endpoint
        return await client.post(path, json_body={"action": action})

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

```python
"""wait_for_state: poll a machine until it reaches one of the target states."""

from __future__ import annotations

import asyncio

from mcp.server.fastmcp import FastMCP

from maasmcp.maas.client import MaasClient
from maasmcp.maas.errors import MCPUpstreamTimeout


class WaitForStateTool:
    name = "wait_for_state"
    description = (
        "Poll a machine's status until it matches one of the target states or "
        "the timeout elapses. Returns the final machine dict."
    )

    async def run(
        self,
        client: MaasClient,
        system_id: str,
        target_states: list[str],
        timeout_seconds: int = 600,
        poll_interval_seconds: float = 5.0,
    ) -> dict:
        deadline = asyncio.get_event_loop().time() + timeout_seconds
        while True:
            machine = await client.get(f"/api/2.0/machines/{system_id}/")
            if isinstance(machine, dict):
                if machine.get("status_name") in target_states:
                    return machine
            if asyncio.get_event_loop().time() >= deadline:
                raise MCPUpstreamTimeout(
                    f"machine {system_id} did not reach {target_states} within {timeout_seconds}s",
                    url=f"/api/2.0/machines/{system_id}/",
                )
            await asyncio.sleep(poll_interval_seconds)

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

````markdown
All settings can come from a YAML config file (`maasmcp serve --config config.yaml`) or `MAASMCP_*` environment variables. Secrets use `${VAR}` indirection so they never sit in committed config:

```yaml
maas:
  base_url: https://maas.example.com/MAAS
  api_key: ${MAAS_API_KEY}
server:
  bearer_token: ${MAASMCP_BEARER_TOKEN}
```

See `docs/superpowers/specs/2026-07-07-maasmcp-design.md` for the full design.
````

```python
from maasmcp.curated.acquire_machine import AcquireMachineTool
from maasmcp.curated.release_machine import ReleaseMachineTool

pytestmark = pytest.mark.e2e


def _config() -> MaasmcpConfig:
    base_url = os.environ["MAASMCP_E2E_URL"]
    api_key = os.environ["MAASMCP_E2E_KEY"]
    # Build a minimal MaasConfig + top-level MaasmcpConfig

    )
    return cfg


@pytest.mark.asyncio

        )
```
