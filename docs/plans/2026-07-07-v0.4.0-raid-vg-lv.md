# v0.4.0 — RAID + Volume Groups + Logical Volumes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the third storage tier (RAID + volume groups + logical volumes) to the maasmcp curated layer — 12 new verbs, 6 new path helpers, and a real-counts `storage_summary` — bringing the curated surface to 43 verbs.

**Architecture:** New verbs follow the v0.3.0/v0.3.1 pattern exactly: one file per verb class, `Annotated[MaasClient, SkipJsonSchema()]` first-param, `_validate_ids` for path validation, `confirm: bool = False` gate on every destructive verb, M2 schema-drift raise on `get_*` and `create_*` verbs that return a single object. `storage_summary` evolves to sequential Stage 1 (`list_block_devices`) + fat Stage 2 (parallel partitions + raids + volume-groups gather). All endpoints come verbatim from `docs/reference/maasapi.md` (RAIDs at lines 8753–8910, VGs at 12191–12426, LV actions at 12311–12377).

**Tech Stack:** Python 3.12+, FastMCP, Pydantic v2, respx (test mocking), pytest-asyncio, ruff, mypy --strict. Same stack as v0.3.0/v0.3.1; no new dependencies.

## Global Constraints

These apply to every task. Re-read before each task's review.

- **No new dependencies.** Same `pyproject.toml` as v0.3.1.
- **`_validate_ids` is the only validator.** Every new verb validates its path IDs through `_validate_ids(system_id, ...)` — never inline `if not system_id` / `if id <= 0` blocks. v0.3.1 closed this duplication finding (M1/M5).
- **`confirm: bool = False` on every destructive verb.** Path validation runs BEFORE the confirm check, preserving the M6 invariant. Destructive verbs in v0.4.0: `create_raid`, `update_raid`, `delete_raid`, `create_volume_group`, `update_volume_group`, `delete_volume_group`, `create_logical_volume`, `delete_logical_volume` (8 total).
- **`Annotated[MaasClient, SkipJsonSchema()]` first-param pattern** on every verb's `run` signature. No FastMCP JSON-schema regressions.
- **MCPUpstreamError body-strip security fix (`5ad4a1a`) preserved.** Tests asserting on upstream errors continue to assert on the status code only (`"409" in str(exc_info.value)`), never on body text.
- **Schema-drift raise on non-dict upstream** (M2). The four M2-raise verbs in v0.4.0: `get_raid`, `get_volume_group`, `create_raid`, `create_volume_group`. Each raises `ValueError(f"MAAS returned non-dict for <kind> <id> (got {type(resp).__name__}); schema drift?")` instead of silently returning `{}`.
- **`MaasClient.post()` signature is `async def post(self, path, *, json=None) -> Any`.** The kwarg name is `json=`, NOT `data=`. Internally (`5ad4a1a`) the client converts the dict to multipart/form-data so MAAS accepts it. All POST/PUT verbs call `client.post(path, json=body)` or `client.put(path, json=body)` with a plain dict.
- **`MaasClient.delete()` exists** for `delete_raid` and `delete_volume_group`. Verify the signature in `src/maasmcp/maas/client.py` before Task 3 / Task 5; if absent, use `client.post(path, json={})` as fallback (per v0.3.0 `delete_block_device` precedent).
- **MAAS authority.** Every endpoint shape, body field name, and response contract comes from `docs/reference/maasapi.md` at the project root.
- **Test fixture pattern (v0.1.1):** Tests that build a `MaasClient` directly via `MaasmcpConfig.load(None)` must first seed env vars because `tests/conftest.py` autouses `_isolate_settings_env` and `MaasmcpConfig` requires `maas`+`server` sub-configs:
  ```python
  monkeypatch.setenv("MAASMCP_MAAS__BASE_URL", "https://maas.example.com/MAAS")
  monkeypatch.setenv("MAASMCP_MAAS__API_KEY", "k")
  monkeypatch.setenv("MAASMCP_SERVER__BEARER_TOKEN", "t")
  ```
  Then `client = MaasClient(cfg.maas)` and assign `client.base_url = cfg.maas.base_url` so `respx.mock(base_url=maas_client.base_url)` targets the right host. Wrap each test body in `async with maas_client:` inside `respx.mock(...)` — MaasClient's inner httpx client is None outside that block (asserted in `client.py:166`). The respx context must be the outer one so it intercepts the httpx client created on `__aenter__`.
- **Local-only, no PyPI publish, no push.** Matches v0.3.0 (`cad89b7`) and v0.3.1 (`c75589b`) precedent.
- **`v0.4.0` tag at post-review HEAD.** No push.

```python
"""list_raids: GET /nodes/{system_id}/raids/."""

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._storage_paths import _validate_ids, raids_path
from maasmcp.maas.client import MaasClient


class ListRaidsTool:
    name = "list_raids"
    description = (
        "List all RAID arrays on a MAAS machine. Returns a list of RAID "
        "dicts (id, name, level, uuid, ...). Use get_raid to fetch one."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
    ) -> list[dict[str, Any]]:
        _validate_ids(system_id)
        resp = await client.get(raids_path(system_id))
        return resp if isinstance(resp, list) else []

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

```python
"""get_raid: GET /nodes/{system_id}/raid/{id}/."""

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._storage_paths import _validate_ids, raid_path
from maasmcp.maas.client import MaasClient


class GetRaidTool:
    name = "get_raid"
    description = (
        "Fetch one RAID array by system_id + raid_id. Returns the MAAS "
        "RAID dict. Use list_raids to find IDs first."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
        raid_id: int,
    ) -> dict[str, Any]:
        _validate_ids(system_id, raid_id=raid_id)
        resp = await client.get(raid_path(system_id, raid_id))
        if not isinstance(resp, dict):
            raise ValueError(
                f"MAAS returned non-dict for raid {raid_id} "
                f"(got {type(resp).__name__}); schema drift?"
            )
        return resp

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

```python
"""create_raid: POST /nodes/{system_id}/raids/."""

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._storage_paths import _validate_ids, raids_path
from maasmcp.maas.client import MaasClient


class CreateRaidTool:
    name = "create_raid"
    description = (
        "Create a RAID array on a MAAS machine. DESTRUCTIVE — you must "
        "pass confirm=True. Returns the newly-created RAID dict."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
        level: int,
        name: str | None = None,
        uuid: str | None = None,
        block_devices: list[int] = [],
        partitions: list[int] = [],
        spare_devices: list[int] = [],
        spare_partitions: list[int] = [],
        confirm: bool = False,
    ) -> dict[str, Any]:
        _validate_ids(system_id)
        if level not in (0, 1, 5, 6, 10):
            raise ValueError(
                f"raid level must be 0, 1, 5, 6, or 10 (got {level})"
            )
        if not (block_devices or partitions):
            raise ValueError(
                "raid requires at least one block device or partition"
            )
        if confirm is not True:
            raise ValueError(
                "create_raid is destructive; pass confirm=True to proceed. "
                f"Affected: system_id={system_id}, level={level}"
            )
        body: dict[str, Any] = {"level": level}
        if name is not None:
            body["name"] = name
        if uuid is not None:
            body["uuid"] = uuid
        if block_devices:
            body["block_devices"] = block_devices
        if partitions:
            body["partitions"] = partitions
        if spare_devices:
            body["spare_devices"] = spare_devices
        if spare_partitions:
            body["spare_partitions"] = spare_partitions
        resp = await client.post(raids_path(system_id), json=body)
        if not isinstance(resp, dict):
            raise ValueError(
                f"MAAS returned non-dict for created raid "
                f"(got {type(resp).__name__}); schema drift?"
            )
        return resp

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

```python
"""create_volume_group: POST /nodes/{system_id}/volume-groups/."""

from __future__ import annotations

from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._storage_paths import _validate_ids, volume_groups_path
from maasmcp.maas.client import MaasClient


class CreateVolumeGroupTool:
    name = "create_volume_group"
    description = (
        "Create a volume group on a MAAS machine. DESTRUCTIVE — you must "
        "pass confirm=True. Requires at least one block device or "
        "partition. Returns the newly-created VG dict."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
        name: str,
        uuid: str | None = None,
        block_devices: list[int] = [],
        partitions: list[int] = [],
        confirm: bool = False,
    ) -> dict[str, Any]:
        _validate_ids(system_id)
        if not name:
            raise ValueError("name must be a non-empty string")
        if not (block_devices or partitions):
            raise ValueError(
                "volume group requires at least one block device or partition"
            )
        if confirm is not True:
            raise ValueError(
                "create_volume_group is destructive; pass confirm=True to proceed. "
                f"Affected: system_id={system_id}, name={name}"
            )
        body: dict[str, Any] = {"name": name}
        if uuid is not None:
            body["uuid"] = uuid
        if block_devices:
            body["block_devices"] = block_devices
        if partitions:
            body["partitions"] = partitions
        resp = await client.post(volume_groups_path(system_id), json=body)
        if not isinstance(resp, dict):
            raise ValueError(
                f"MAAS returned non-dict for created volume group "
                f"(got {type(resp).__name__}); schema drift?"
            )
        return resp

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```

```python
"""storage_summary: sequential Stage 1 (devices), fat Stage 2 (partitions + raids + VGs)."""

from __future__ import annotations

import asyncio
from typing import Annotated, Any

from mcp.server.fastmcp import FastMCP
from pydantic.json_schema import SkipJsonSchema

from maasmcp.curated._storage_paths import (
    _validate_ids,
    block_devices_path,
    partitions_path,
    raids_path,
    volume_groups_path,
)
from maasmcp.maas.client import MaasClient


def _to_gib(size_bytes: int) -> float:
    """Convert bytes (MAAS may return as int or string) to GiB."""
    try:
        n = int(size_bytes)
    except (TypeError, ValueError):
        return 0.0
    return round(n / (1024 ** 3), 2)


def _parse_block_devices(resp: Any) -> list[dict[str, Any]]:
    """Accept wrapped {"blockdevices": [...]} or bare-list shapes."""
    if isinstance(resp, dict) and "blockdevices" in resp:
        return list(resp["blockdevices"])
    if isinstance(resp, list):
        return resp
    return []


def _parse_raids(resp: Any) -> list[dict[str, Any]]:
    """Accept wrapped {"raids": [...]} or bare-list shapes."""
    if isinstance(resp, dict) and "raids" in resp:
        return list(resp["raids"])
    if isinstance(resp, list):
        return resp
    return []


def _parse_volume_groups(resp: Any) -> list[dict[str, Any]]:
    """Accept wrapped {"volume_groups": [...]} or bare-list shapes."""
    if isinstance(resp, dict) and "volume_groups" in resp:
        return list(resp["volume_groups"])
    if isinstance(resp, list):
        return resp
    return []


def _count_lvs_in_vg(vg: dict[str, Any]) -> int:
    """Best-effort extraction of LV count from a VG dict.

    Tries ``logical_volumes`` first (MAAS docs terminology at
    docs/reference/maasapi.md:12311), then ``volumes``. Returns 0 on neither match
    (the agent still sees correct RAID/VG counts).
    """
    for key in ("logical_volumes", "volumes"):
        member = vg.get(key)
        if isinstance(member, list):
            return len(member)
    return 0


class StorageSummaryTool:
    name = "storage_summary"
    description = (
        "Cross-resource read of a machine's storage layout: block_device "
        "count, partition count, total size in GiB, plus raid_devices, "
        "volume_groups, and logical_volumes counts. Sequential Stage 1 "
        "(list_block_devices), fat Stage 2 (parallel per-device "
        "partitions + list_raids + list_volume_groups)."
    )

    async def run(
        self,
        client: Annotated[MaasClient, SkipJsonSchema()],
        system_id: str,
    ) -> dict[str, Any]:
        _validate_ids(system_id)

        # Stage 1: block devices (sequential — sizes Stage 2 partition fan-out)
        devices_resp = await client.get(block_devices_path(system_id))
        devices = _parse_block_devices(devices_resp)

        # Stage 2: per-device partitions + raids + volume-groups in parallel
        partition_lists, raids_resp, vgs_resp = await asyncio.gather(
            *(client.get(partitions_path(system_id, d["id"])) for d in devices),
            client.get(raids_path(system_id)),
            client.get(volume_groups_path(system_id)),
            return_exceptions=True,
        )

        partitions = 0
        for pl in partition_lists:
            if isinstance(pl, Exception):
                continue
            if isinstance(pl, dict) and "partitions" in pl:
                partitions += len(pl["partitions"])
            elif isinstance(pl, list):
                partitions += len(pl)

        raids = _parse_raids(raids_resp)
        vgs = _parse_volume_groups(vgs_resp)
        logical_volumes = sum(_count_lvs_in_vg(vg) for vg in vgs)
        total_gib = sum(_to_gib(d.get("size", 0)) for d in devices)

        return {
            "system_id": system_id,
            "block_devices": len(devices),
            "partitions": partitions,
            "total_size_gb": total_gib,
            "raid_devices": len(raids),
            "volume_groups": len(vgs),
            "logical_volumes": logical_volumes,
        }

    def register(self, mcp: FastMCP) -> None:
        mcp.add_tool(self.run, name=self.name, description=self.description)
```
